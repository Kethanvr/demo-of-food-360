# Food-360 demo

A single-page food-product showcase for MTR Poha, built with HTML, CSS, and JavaScript. The page uses external web assets such as Tailwind CSS and Google Fonts.

## View locally

Open `index.html` in a browser. The page needs an internet connection for the CDN-hosted styling and fonts.

The repository is a small static demo; it does not include a server, shopping flow, or product data service.
